1. O que o plugin faz

O plugin funciona como uma camada de interpretação acadêmica sobre os cursos do Moodle. Ele lê dados técnicos dispersos — permissões, papéis, categorias, datas e campos customizados — e converte tudo em uma interface orientada ao usuário.

Moodle roles/capabilities Cronograma da disciplina Categorias acadêmicas Janela vigente

A proposta não é listar cursos: é reduzir ansiedade, priorizar o semestre certo e mostrar somente o que faz sentido para cada papel.

Do Moodle técnico para uma agenda acadêmica

O bloco traduz uma estrutura complexa em quatro perguntas simples:

  1. Quem é esta pessoa?
  2. Quais disciplinas importam agora?
  3. Em que estado cada disciplina está?
  4. Quais filtros ajudam sem poluir?

O que está escondido nessa simplicidade

  • Escolha automática da perspectiva padrão.
  • Contagem por abas atualizada pelos filtros.
  • Separação entre cronograma completo e ausência de dados.
  • Filtros em cascata por categoria acadêmica.
  • Links respeitando a decisão de produto para cada papel.

Princípio visual

A interface deve ser “aliviante”: o usuário vê uma organização confiável, não a bagunça dos dados de origem.

6. Regras de dados que viraram produto

Dado técnicoInterpretação do pluginBenefício para gestão
ead_inicio + ead_final Cronograma completo da disciplina EaD. Permite identificar o que está aberto, futuro ou encerrado.
Ausência parcial/total de cronograma Estado complementar “Sem data”. Expõe lacunas para equipe sem gerar ansiedade no aluno.
Árvore de categorias Nível, modalidade, curso, turma e reoferta. Transforma organização institucional em filtros úteis.
Roles e capabilities Perspectiva disponível para o usuário. Evita telas genéricas: cada pessoa vê o que seu papel demanda.
course.startdate/enddate Janela Moodle auxiliar quando falta cronograma. Ajuda a localizar disciplinas prováveis do semestre mesmo com dados incompletos.
