Leitura executiva do diagrama

O plugin não cria um novo cadastro acadêmico

Ele interpreta dados já existentes no Moodle e os reorganiza em uma visão acadêmica confiável.

O valor está nas entidades derivadas

Perspectiva, Card, Filtros e Resumo são a camada inteligente que transforma dados técnicos em decisão visual.

Cardinalidades e decisões principais

Relação Cardinalidade conceitual Regra importante
Usuário → Vínculo/Papel → Curso Usuário pode ter muitos vínculos em muitos cursos. O plugin resolve a perspectiva a partir dos vínculos reais.
Curso → Categoria Curso pertence a uma posição na árvore de categorias. Categoria é fonte principal para filtros acadêmicos.
Curso → Cronograma EaD Curso EaD pode ter cronograma completo, incompleto ou ausente. Completo exige ead_inicio + ead_final.
Janela acadêmica → Card A janela decide se uma disciplina pertence ao semestre vigente. Evita que cursos de janeiro contaminem o semestre seguinte.
Card → Resumo renderizado Muitos cards são agrupados em abas por status. Contadores mudam conforme filtros e perspectiva.
Presencial planejado → Filtros Presencial terá filtros próprios derivados da categoria. Não usa Tipo/Oferta/Reoferta.
