# Triage Labels

As skills usam cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para as labels reais usadas no GitHub Issues deste repo.

| Label em mattpocock/skills | Label no nosso tracker | Significado |
| -------------------------- | ---------------------- | ----------- |
| `needs-triage`             | `precisa-triagem`      | Mantenedor precisa avaliar a issue |
| `needs-info`               | `precisa-informacao`   | Aguardando mais informação de quem reportou |
| `ready-for-agent`          | `pronto-para-agente`   | Totalmente especificada, pronta para um agente AFK |
| `ready-for-human`          | `pronto-para-humano`   | Precisa de implementação humana |
| `wontfix`                  | `nao-sera-feito`       | Não será executada |

Quando uma skill mencionar um papel canônico, aplique a label correspondente da coluna "Label no nosso tracker".

Se as labels forem renomeadas no GitHub, atualize este arquivo antes de usar `triage`, `to-issues` ou `to-prd`.
